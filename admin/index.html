거래처 관리

거래처 정보를 등록하고, 식수 접수용 장부 확인번호를 관리합니다.

거래처 목록을 불러오는 중입니다.

새 거래처 등록

회사명은 필수이며, 나머지 항목은 필요한 만큼 입력할 수 있습니다.

식수 접수 화면에서 별칭으로도 거래처를 찾을 수 있습니다.
거래처별 식대가 다를 경우에만 수정하세요.

식수 입력 방식 설정

거래처별 기본 입력 방식을 정합니다. 기존 거래처는 별도 설정이 없어도 혼합 방식으로 동작합니다.

식수 접수 화면에 처음 들어왔을 때 선택되는 방식입니다.
해제하면 접수 화면에서 입력 방식을 바꿀 수 없습니다.

사전 등록 명단 관리

거래처를 선택한 뒤 이름을 한 줄에 한 명씩 입력해 등록합니다. 이미 등록된 이름은 중복 저장하지 않습니다.

거래처를 선택해 주세요.

거래처 장부 확인번호 관리

등록된 거래처를 선택해 장부 번호에 맞는 숫자 3자리 확인번호를 설정하거나 해제합니다.

장부 번호를 3자리로 입력합니다. 예: 장부 3번 → 003. 확인번호는 편의용 확인값이며 보안 인증 수단이 아닙니다.
